Öncelikle Merhaba. Bu benim ilk büyük çaplı projem o yüzden projede fazlaca hata olabilir.

Bu projede veri tabanı olarak MySQL kullandım. Proje dili olarak HTML, CSS, PHP ve JS kullandım.

connection.php dosyası PHPMyAdmin sayfasına göre ayarlı. Eğer kendi sisteminizdeki MySQL'de kullanmak isterseniz $servername'e kendi localhost id'nizi yazınız. Ardından $username'e MySQL'deki adını, $password'e MySQL şifreniz ve en son $dbname'e kendi database adınızı yazınız. Bu şekilde kendi sisteminizdeki MySQL'e bağlayabilirsiniz.
